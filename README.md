                                캡스톤 디자인 프로젝트 : 여행사무소(Travel_Office)

외교부 공공 데이터를 활용하여 국가별 안전 등급 및 여행 유의사항을 직관적으로
제공하는 안전 여행 가이드 플랫폼

**1. 프로젝트 배경 및 목적**
- 문제 제기: 해외여행 수요는 급증하고 있으나, 국가별 실시간 안전 정보(테러, 전염병, 치안 등)를 확인하려면 외교부 사이트나 뉴스를 검색해보아야하는 번거로움이 있음.

- 해결 방안: 외교부 공공 데이터 API를 연동하여 시각화된 안전 지도를 제공하고, OPEN API를 사용하여 사용자 맞춤형 안전 체크리스트를 제공함.

**2. 주요 핵심 기능**
```
     기능                               분류 상세 내용

안전 등급 시각화    외교부 국가별 여행경보 단계(1~4단계)를 지도상에 색상으로 표시

실시간 뉴스 피드    해당 국가의 최신 사건/사고 및 재난 정보 크롤링 또는 API 연동

국가별 필수 정보    전압, 비자 필요 여부, 긴급 연락처(현지 영사관 등) 안내

 안전 커뮤니티      최근 해당 국가를 방문한 또는 거주 중인 사용자들의 실시간 치안 후기 공유

체크리스트 생성     여행지 등급에 따른 맞춤형 준비물 및 보험 가입 권장 리스트

 GPS 위치 연동      사용자의 현재 위치를 표시하여 다른 사용자와 공유
```

**3. 기술 스택**
- Frontend: React.js
- Backend: Node.js(Express) - Database: MySQL
- Data Source: 외교부 국가/지역별 여행 경보, 외교부_최신안전 소식 API 활용

**4. 인프라**
- Frontend: React
- Backend: AWS EC2
- Database: DBeaver, Supabase
- Domain, DNS: Route 53 / 가비아

**6. 차별점**
- 데이터의 시각화: 안전 단계별 색상 코드 적극 활용, 한 눈에 들어오는 UI - 실시간성: 외교부 업데이트는 주기가 있으므로, 최신 뉴스 크롤링 기능을 덧붙여 프로젝트 완성도 높임
